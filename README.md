
# Simple Interest Calculator

This project calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal: The initial amount of money.
- Rate: The annual rate of interest in percent.
- Time: The period in years.

## Output

The calculator displays the simple interest calculated from the provided values.

## Usage

Run the `simple-interest.sh` script in a Bash terminal and enter the principal amount, rate of interest, and time period when prompted.

## Example

Principal = 1000  
Rate = 5%  
Time = 2 years

Simple Interest = 100
